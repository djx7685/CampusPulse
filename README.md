# CampusPulse

CampusPulse is a responsive campus community hub prototype for discovering student events, clubs, study circles, and secondhand listings.

## Run locally

Open `index.html` in a modern browser. The demo is static and has no build step or external service dependency. Google Fonts are an optional visual enhancement; the page falls back to system fonts if they are unavailable.

## Current prototype interactions

- Save or unsave an event or marketplace listing.
- Join the sample study circle.
- Open the create menu for a future event, club, or listing workflow.
- Search the visible sample content.

The sample data and interactions are for demonstration only. There is no account system, backend, live campus feed, or persistence.
